## ADDED Requirements

### Requirement: Teacher class selection landing page and context switching
After a teacher logs in, the system SHALL display a "Select a Class" screen listing all classes assigned to them. Selecting a class switches the application context, filtering all pages and data by that class.

#### Scenario: Switching classes
- **WHEN** Teacher selects a class in the landing screen or header dropdown switcher
- **THEN** The application context changes to the selected class, filtering subjects, students, and textbook contents immediately
