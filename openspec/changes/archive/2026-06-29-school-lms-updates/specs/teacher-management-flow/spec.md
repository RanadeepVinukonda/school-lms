## ADDED Requirements

### Requirement: Centralized teacher creation and selection-only assignment
Teacher creation SHALL only occur under Class Hub -> Teachers Tab -> Create Teacher. The "Assign Teacher" page/dialog SHALL only support selecting from existing teachers.

#### Scenario: Assigning a teacher
- **WHEN** Admin opens the Assign Teacher dialog for a subject
- **THEN** The system shows a selector listing only existing teachers in the system, without options to create a new teacher
