## ADDED Requirements

### Requirement: Test template builder and AI question generation
The system SHALL support creating, saving, and editing test templates with a real-time live preview, and allow teachers to manually add questions or generate additional questions using AI.

#### Scenario: Generating questions with AI
- **WHEN** Teacher triggers AI question generation within a test template
- **THEN** The system generates questions, inserts them into the template, and saves them to the concept's question bank
