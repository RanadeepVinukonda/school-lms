## ADDED Requirements

### Requirement: Restrict student content visibility to pushed items
Students SHALL only see notes, resources, mindmaps, lectures, and tests that the teacher has explicitly pushed. Otherwise, students only see progress tracking information.

#### Scenario: Student opening a concept page
- **WHEN** Student views a concept page
- **THEN** The system hides any notes, resources, mindmaps, lectures, or tests that have not been explicitly pushed by the teacher
