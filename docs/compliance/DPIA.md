## 2. Processing Overview

### Data Categories Processed
- **Students**: Name, email, grade, attendance, fee records, assignments, messages, photos
- **Teachers**: Name, email, class assignments, salary, attendance, qualifications
- **Parents**: Name, email, children relationship
- **Admins**: Name, email, school configuration

### Processing Purposes
1. Academic management (grades, attendance, exams)
2. Financial management (fee structures, payments)
3. Communication (messages, notifications)
4. AI-powered content generation (textbook processing, question generation)
5. Platform analytics and improvement

### Legal Basis
- Contract (Art. 6(1)(b)): Core educational services
- Legal obligation (Art. 6(1)(c)): Records retention for audits
- Consent (Art. 6(1)(a)): Photos, push notifications, AI features
- Legitimate interest (Art. 6(1)(f)): Platform analytics

## 3. Data Flow Mapping

### Collection
- Direct from users (registration, profile)
- Generated by system (grades, attendance)
- Uploaded by users (photos, assignments)

### Storage
- Primary: PostgreSQL (Supabase) — encrypted at rest
- Media: Cloudinary
- Cache: Redis (transient, no PII)

### AI Processing
- Textbook PDFs sent to Google Gemini / OpenRouter for OCR and content extraction
- No PII shared with AI providers
- Processing EU/appropriate jurisdiction

## 4. Risk Assessment

| Risk | Likelihood | Impact | Mitigation |
|------|-----------|--------|------------|
| Unauthorized access (breach) | Low | High | Encryption, access controls, audit logs |
| Data loss | Low | Critical | Daily backups, PITR, restore drills |
| AI provider data leakage | Low | Medium | No PII shared, data minimization |
| Excessive data collection | Low | Medium | Data retention schedules, deletion endpoints |
| Inadequate consent | Medium | Medium | Granular consent options, withdrawal support |

## 5. Data Protection Measures
- [x] Pseudonymization where possible
- [x] Encryption at rest and in transit
- [x] Access controls (role-based + school-scoped)
- [x] Audit logging of all data access
- [x] Data retention schedules enforced
- [x] Deletion endpoints (GDPR right to erasure)
- [x] Data portability endpoint (GDPR right to access)

## 6. Third-Party Processors

- [x] Right to rectification: Profile update in settings
- [x] Right to portability: JSON export format
